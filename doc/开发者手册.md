# 开发者手册

## 环境要求

- **操作系统**: Windows（不支持 Win7 和 Mac）
- **Python**: 3.10 及以上版本
- **微信**: 已安装并登录的微信客户端（支持微信 3.x 和 4.0 版本）

## 安装步骤

### 1. 克隆仓库

```bash
git clone https://github.com/LC044/WeChatMsg.git
cd WeChatMsg
```

### 2. 创建虚拟环境（推荐）

```bash
# 使用 venv 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

## 使用指南

### 第一步：解析微信数据库

运行解密脚本，从本地微信客户端获取并解密数据库：

```bash
cd example
python 1-decrypt.py
```

**说明：**
- 脚本会自动检测已登录的微信账号
- 根据你的微信版本修改脚本中的函数调用：
  - 微信 3.x：使用 `dump_v3()`
  - 微信 4.0：使用 `dump_v4()`
- 成功后会在当前目录生成 `wxid_xxx` 文件夹
- 数据库文件位置：
  - 微信 4.0：`./wxid_xxx/db_storage/`
  - 微信 3.x：`./wxid_xxx/Msg/`

**常见问题：**
- 如果提示"未找到key"，请重启微信后重试
- 确保微信客户端正在运行
- 需要管理员权限时，请右键以管理员身份运行

### 第二步：查看联系人

查看所有联系人和群聊信息：

```bash
python 2-contact.py
```

**配置说明：**

修改 `2-contact.py` 文件中的以下参数：

```python
db_dir = './wxid_xxx/db_storage'  # 第一步生成的数据库路径
db_version = 4  # 数据库版本: 4 表示微信4.0，3 表示微信3.x
```

脚本会输出：
- 所有联系人的 wxid、昵称、备注等信息
- 群聊成员列表
- 联系人总数和耗时

### 第三步：导出聊天记录

将聊天记录导出为各种格式：

```bash
python 3-exporter.py
```

**配置说明：**

修改 `3-exporter.py` 文件中的以下参数：

```python
db_dir = './wxid_xxx/db_storage'  # 数据库路径
db_version = 4  # 数据库版本
wxid = 'wxid_00112233'  # 要导出的联系人 wxid（在第二步中获取）
output_dir = './data/'  # 导出文件保存路径
```

**支持的导出格式：**

1. **HTML格式**（推荐）：
   - 完整还原聊天界面
   - 支持文本、图片、视频、表情包、语音、文件等
   - 支持时间轴跳转、引用消息定位
   
   ```python
   exporter = HtmlExporter(database, contact, output_dir=output_dir, type_=FileType.HTML)
   ```

2. **TXT格式**：纯文本格式
   ```python
   exporter = TxtExporter(database, contact, output_dir=output_dir, type_=FileType.TXT)
   ```

3. **DOCX格式**：Word文档格式
   ```python
   exporter = DocxExporter(database, contact, output_dir=output_dir, type_=FileType.DOCX)
   ```

4. **JSON格式**：用于AI训练
   ```python
   exporter = JsonExporter(database, contact, output_dir=output_dir, type_=FileType.JSON)
   ```

5. **XLSX格式**：Excel表格格式
   ```python
   exporter = ExcelExporter(database, contact, output_dir=output_dir, type_=FileType.XLSX)
   ```

6. **Markdown格式**：Markdown文档格式
   ```python
   exporter = MarkdownExporter(database, contact, output_dir=output_dir, type_=FileType.MARKDOWN)
   ```

**高级选项：**

```python
exporter = HtmlExporter(
    database,
    contact,
    output_dir=output_dir,
    type_=FileType.HTML,
    message_types={MessageType.Text, MessageType.Image},  # 指定导出的消息类型
    time_range=['2020-01-01 00:00:00', '2024-12-31 23:59:59'],  # 指定时间范围
    group_members=['wxid_aaa', 'wxid_bbb']  # 仅导出群聊中特定成员的消息
)
```

### 第四步（可选）：批量导出

批量导出所有联系人的聊天记录：

```python
# 在 3-exporter.py 中调用
if __name__ == '__main__':
    freeze_support()
    batch_export()  # 批量导出所有联系人
```

## 常见问题

### 1. 程序闪退

- 右键选择"以管理员身份运行"
- 删除 `app/Database/Msg` 文件夹
- 重启微信
- 重启电脑

### 2. 提示"未找到key"

- 确保微信客户端正在运行
- 重启微信后重试
- 如果 key 显示为 "none"，请重启电脑

### 3. 导入依赖包失败

```bash
# 如果安装依赖失败，可以尝试换源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 4. 微信版本不匹配

- 确认你的微信版本（在微信"设置"->"关于微信"中查看）
- 在脚本中正确设置 `db_version`：
  - 微信 4.0.x：`db_version = 4`
  - 微信 3.x.x：`db_version = 3`

### 5. 找不到wxid

运行第二步 `2-contact.py` 查看所有联系人的 wxid，然后复制正确的 wxid 到导出脚本中。

## 性能优化建议

- 导出大量数据时，建议关闭其他占用内存的应用
- 使用 SSD 硬盘可以显著提升导出速度
- 可以通过 `message_types` 参数只导出需要的消息类型，减少处理时间
